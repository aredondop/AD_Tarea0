# Acceso a Datos - Tarea 0

## Módulo
Acceso a Datos

## Ciclo formativo
Desarrollo de Aplicaciones Multiplataforma (DAM)

## Tarea
Tarea 0 - Creación de un programa en Java

## Descripción

Proyecto realizado para la unidad inicial del módulo de Acceso a Datos.

El ejercicio consiste en desarrollar una aplicación básica en Java que permita:

- Crear una clase `Coche`.
- Definir los atributos `marca`, `modelo`, `anyo` y `matricula`.
- Utilizar una variable de clase `contador_de_coches`.
- Implementar un constructor por defecto y otro constructor con parámetros.
- Implementar métodos getter y setter.
- Solicitar datos mediante teclado utilizando `Scanner`.
- Almacenar objetos `Coche` en un `ArrayList`.
- Mostrar por pantalla el número total de coches creados y los datos de cada uno.

## Estructura

- `Coche.java`: clase que representa cada vehículo.
- `Concesionario.java`: clase principal que contiene el método `main()` y gestiona la entrada y salida de datos.

## Tecnologías

- Java
- NetBeans
- `java.util.Scanner`
- `java.util.ArrayList`
